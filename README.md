# Python Testing & Async Examples

## Overview
This repository contains practical examples of testing and asynchronous programming in Python. It demonstrates the ability to write unit tests with PyTest and use `asyncio` for non-blocking operations.

## Features
- **Unit Testing:** Tests for a BMR (Basal Metabolic Rate) calculator using PyTest.
- **Asynchronous Programming:** A comparison between synchronous (blocking) and asynchronous (non-blocking) execution using `asyncio`.

## Files
- `calc.py`: The BMR calculation logic.
- `test_calc.py`: PyTest unit tests for the calculator.
- `async_lesson.py`: Example of running tasks synchronously vs asynchronously.

## Tech Stack
- **Language:** Python
- **Testing:** PyTest
- **Async:** asyncio
